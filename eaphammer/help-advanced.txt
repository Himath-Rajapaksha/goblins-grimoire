options:
  -h, --help            show this help message and exit
  --manual-config config_file
                        Bypass eaphammer's hostapd configuration manager and
                        load your own hostapd.conf file instead.
  --save-config         Save hostapd config file on exist.
  --save-config-only    Don't actually run anything. Instead, just generate a
                        hostapd config file using user supplied parameters
                        then exit.
  --debug               Enable debug output.
  --advanced-help, -hh  Show extended help options then exit.

Modes:
  --version, -V         Print version info
  --cert-wizard [{create,import,interactive,list,dh}]
                        Use this flag to run in Cert Wizard mode. Use "--cert-
                        wizard create" to create a new certificate. Use "--
                        cert-wizard interactive" or simply "--cert-wizard" to
                        run Cert Wizard in interactive mode. Use "--cert-
                        wizard import" to import a set of certificates into
                        eaphammer's static configuration. Use "--cert-wizard
                        list" to list all previously imported certs, as well
                        as the active cert configuration. Use "--cert-wizard
                        dh" to manually regenerate eaphammer's dh parameters.
  --list-templates      List available templates for the captive portal
  --create-template     Create a template by cloaning a login page
  --delete-template     Delete a captive portal template.
  --bootstrap           Shorthand for "--cert-wizard create --self-signed"
  --creds, --brad       Harvest EAP creds using evil twin attack
  --pmkid               Perform clientless attack against PSK network using
                        ZerBea's hcxtools.
  --troll-defender      Trigger Windows Defender on nearby devices by spawning
                        an AP with SSID set to C:\Temp\Invoke-Mimikatz.ps1
  --eap-spray           Check for password reuse by spraying a single password
                        across a series of usernames against target ESSID.
  --hostile-portal      Force clients to connect to hostile portal
  --captive-portal-server-only
                        Run the captive portal server as astandalone service.
  --captive-portal      Force clients to connect to a captive portal

Cert Wizard:
  --server-cert SERVER_CERT
                        Specify path to server cert file. Can be used with "--
                        cert-wizard import" to import a cert or cert chain, or
                        with any attack to override eaphammer's static
                        configuration. File must be in PEM format and may
                        contain full certificate chain and/or private key. If
                        file does not contain private key, the --private-key
                        flag should be used. Likewise, if the file does not
                        contain a CA certificate chain, the --ca-cert flag
                        should be used.
  --ca-cert CA_CERT     Specify path to ca cert file.
  --private-key PRIVATE_KEY
                        Specify path to private key file.
  --private-key-passwd PRIVATE_KEY_PASSWD
                        Specify private key password.
  --self-signed         Combine with "--cert-wizard create" to create a self-
                        signed cert.
  --cn CN               Specify certificate CN when running --bootstrap or "--
                        cert-wizard create".
  --country COUNTRY     Specify certificate country when running --bootstrap
                        or "--cert-wizard create".
  --state STATE         Specify certificate state or province when running
                        --bootstrap or "--cert-wizard create".
  --locale LOCALE       Specify certificate locale (city) attribute when
                        running --bootstrap or "--cert-wizard create".
  --org ORG             Specify certificate organization when running
                        --bootstrap or "--cert-wizard create".
  --org-unit ORG_UNIT   Specify certificate org unit when running --bootstrap
                        or "--cert-wizard create".
  --email EMAIL         Specify certificate emailAddress attribute when
                        running --bootstrap or "--cert-wizard create".

Cert Wizard Advanced Options:
  --not-before NOT_BEFORE
                        Specify datetime on which cert should become active.
  --not-after NOT_AFTER
                        Specify datetime on which cert should become active.
  --algorithm ALGORITHM
                        Specify algorithm with which to sign cert.
  --key-length KEY_LENGTH
                        Specify default certificate key length.
  --dh-file DH_FILE     Manually specify path to dh_file at runtime.
  --ca-key CA_KEY       Specify path to CA private key file.
  --ca-key-passwd CA_KEY_PASSWD
                        Specify CA key password.

Access Point:
  --lhost LHOST         Your AP's IP address
  -i, --interface INTERFACE
                        The phy interface on which to create the AP
  -e, --essid ESSID     Specify access point ESSID
  -b, --bssid BSSID     Specify access point BSSID
  -c, --channel CHANNEL
                        Specify access point channel (default: 1).
  --hw-mode HW_MODE     Specify access point hardware mode (defaults: g for
                        2.4GHz channels, a for 5GHz channels).
  --cloaking {none,full,zeroes}
                        Send empty SSID in beacons and ignore probe request
                        frames that do not specify full SSID (i.e. require
                        stations to know SSID). Choices: [1. none - do not use
                        SSID cloaking. ] [2. full - Send empty string in
                        beacon and ignore probe requests for broadcast SSID ]
                        [3. zeroes - Replace all characters in SSID with ASCII
                        0 and ignore probe requests for broadcast SSID.]
  --auth {open,wpa-psk,wpa-eap,owe,owe-transition,owe-psk}
                        Specify authentication mechanism (hostile and captive
                        portal default: open )(creds default: wpa-eap).
  --pmf {disable,enable,require}
                        Enable, disaable, or require the use of Protected
                        Management Frames (PMF) (802.11w) (default: disable)
                        (OWE default: require).
  --karma, --mana       Enable karma.
  --essid-stripping {\r,\n,\t,\x20}
                        Enable ESSID Stripping adding \r.
  --mac-whitelist MAC_WHITELIST
                        Enable MAC address whitelisting and specify path to
                        whitelist file.
  --mac-blacklist MAC_BLACKLIST
                        Enable MAC address blacklisting and specify path to
                        blacklist file.
  --ssid-whitelist SSID_WHITELIST
                        Enable MAC address whitelisting and specify path to
                        whitelist file.
  --ssid-blacklist SSID_BLACKLIST
                        Enable MAC address blacklisting and specify path to
                        blacklist file.

Karma Options:
  --loud, --singe       Enable loud karma mode.
  --known-beacons       Enable persistent known beacons attack.
  --known-ssids-file KNOWN_SSIDS_FILE
                        Specify the wordlist to use with the --known-beacons
                        features.
  --known-ssids KNOWN_SSIDS [KNOWN_SSIDS ...]
                        Specify known ssids via the CLI

AP Advanced Options:
  --wmm                 Enable wmm (further configuration of wmm performed in
                        hostapd.ini)
  --driver DRIVER       Specify driver.
  --beacon-interval TUs
                        Send beacon packets every n Time Units (TUs). A single
                        TU is equal to 1024 microseconds. (default: 100)
  --dtim-period n       Transmit broadcast frames after every n beacons, where
                        n is an integer between 1 and 255. (default: 1)
  --max-num-stations MAX_NUM_STATIONS
                        The maximum number of stations that can connect to the
                        AP at any one time. (default: 255)
  --rts-threshold OCTETS
                        Sets the RTS threshold in octets. (default: 2347)
  --fragm-threshold OCTETS
                        Sets the fragmentation threshold in octets. (default:
                        2346)

802.11n Options:
  Used when --hw-mode is set to "n"

  --channel-width MGhz  Set the channel width in MGHz (single 20 MGHz spatial
                        stream or two 20 MGHz spatial streams totalling 40
                        MGHz). (default: 20)

802.11n Advanced Options:
  --smps {off,dynamic,static}
                        Spatial Multiplexing (SM) Power Save
  --ht40 {plus,minus,auto}
                        Specifies whether the secondary channel should be
                        higher (plus) or lower (minus) than the primary
                        channel. (default: auto)
  --max-spatial-streams {1,2,3}
                        Specifies maximum number of spatial streams. (default:
                        2)
  --obss-interval OBSS_INTERVAL
                        Look this up if you don't know what it does. You
                        probably don't need it. (default: 0)
  --greenfield          Enable greenfield mode.
  --ht-delayed-block-ack
                        Use HT Delayed Block ACK.
  --short-gi            Enable short GI (20 or 40 depending on channel width
  --lsig-txop-prot      Enable L-SIG TXOP Protection support.
  --require-ht          Reject associations from clients that do not support
                        HT.
  --dsss-cck-40         Enable DSSS/CCK Mode in 40MHz.
  --disable-tx-stbc     Disable TX-STBC.
  --ldpc                Enable LDPC Coding capability.
  --use-max-a-msdu-length
                        Set A-MSDU length to maximum allowable value (7935
                        octets). If not set, 3839 octets are used.

WPA-PSK Options:
  Only applicable if --auth wpa-psk is used

  --wpa-passphrase WPA_PASSPHRASE
                        Set WPA Passphrase for AP.

WPA Options:
  Only applicable if --auth wpa-psk or wpa-eap are used

  --capture-wpa-handshakes {yes,no}
                        Capture 4-way WPA handshakes (wpa-psk default: yes)
                        (wpa-eap and sae defaults: no)
  --psk-capture-file PSK_CAPTURE_FILE
                        Path to which to write WPA handshakefiles (default:
                        automatically generated from nonce and current
                        timestamp)
  --auth-alg {shared,open,both}
                        Authentication type (open or shared key). (default:
                        shared)
  --wpa-version {1,2}   Set WPA version. (default: 2)

OWE Transition Mode Options:
