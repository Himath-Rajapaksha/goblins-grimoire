Manage VEX repositories

Usage:
  trivy vex repo [command]

Examples:
  # Initialize the configuration file
  $ trivy vex repo init

  # List VEX repositories
  $ trivy vex repo list

  # Download the VEX repositories
  $ trivy vex repo download


Available Commands:
  download    Download the VEX repositories
  init        Initialize a configuration file
  list        List VEX repositories

Flags:
  -h, --help   help for repo

Global Flags:
      --cacert string             Path to PEM-encoded CA certificate file
      --cache-dir string          cache directory (default "/home/user/.cache/trivy")
  -c, --config string             config path (empty string disables loading) (default "trivy.yaml")
  -d, --debug                     debug mode
      --generate-default-config   write the default config to trivy-default.yaml
      --insecure                  allow insecure server connections
  -q, --quiet                     suppress progress bar and log output
      --timeout duration          timeout (default 5m0s)
  -v, --version                   show version

Use "trivy vex repo [command] --help" for more information about a command.
